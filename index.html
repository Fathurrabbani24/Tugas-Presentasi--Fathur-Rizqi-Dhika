Struktur Codingan C++ yang Digunakan

Header Library & Variabel

  • #include <iostream> : Input/Output stream (cin, cout).
  • #include <string> : Tipe data teks untuk nama barang.
  • #include <cmath> : Perhitungan matematika sqrt() dan round().
  • #include <iomanip> : Format presisi angka desimal setprecision(2).

Nilai Konstan Otomatis

Program secara otomatis mendefinisikan konstanta perhitungan tanpa perlu diinput manual setiap kali perhitungan:

float hariKerja = 300.0f; // Operational days
float safetyStock = 200.0f; // Safety stock level
Slide 3 • Kontrol Alur Pemrograman

Logika Perulangan (WHILE) & Percabangan (IF-ELSE)

1. Perulangan (WHILE Loop)

Digunakan untuk mengulang pengujian atau kalkulasi data barang lain selama variabel ulang bernilai 'y' atau 'Y'.

while (ulang == 'y' || ulang == 'Y') {
  // ... blok perhitungan barang ...
  cout << "Hitung barang lain? (y/n): ";
  cin >> ulang;
}

2. Percabangan (IF-ELSE)

Memeriksa kondisi apakah stokSaatIni kurang dari atau sama dengan nilai rop untuk memberikan status peringatan reorder.

if (stokSaatIni <= rop) {
  cout << "STATUS: PERINGATAN! Segera reorder!\n";
} else {
  cout << "STATUS: AMAN. Stok masih di atas ROP.\n";
}

Hitung Rumus Industri & Percabangan IF-ELSE

C++ Source Code 
        // Perhitungan Rumus Industri (EOQ, ROP, TIC)
        float eoq = sqrt((2.0f * D * S) / H);
        float frekuensi = D / eoq;
        float demandHarian = D / hariKerja;
        float rop = (demandHarian * L) + safetyStock;
        float totalBiaya = (frekuensi * S) + ((eoq / 2.0f) * H);

        // Output Hasil Analysis
        cout << "\n================ HASIL ================\n";
        cout << fixed << setprecision(2);
        cout << "EOQ (Jumlah Pesan Optimal) : " << round(eoq) << " unit\n";
        cout << "ROP (Titik Pesan Ulang)    : " << round(rop) << " unit\n";
        cout << "Total Biaya Persediaan     : Rp " << totalBiaya << "\n";
        cout << "------------------------------------------\n";

        // 2. STRUKTUR PERCABANGAN (IF-ELSE)
        if (stokSaatIni <= rop) {
            cout << "STATUS: PERINGATAN! Stok <= ROP. Segera reorder!\n";
        } else {
            cout << "STATUS: AMAN. Stok masih di atas ROP.\n";
        }
        cout << "==========================================\n";

        // Kontrol Perulangan WHILE
        cout << "\nHitung barang lain? (y/n): ";
        cin >> ulang;
        cout << "\n";
    }

    cout << "Program Selesai. Terima Kasih!\n";
    return 0;
}
